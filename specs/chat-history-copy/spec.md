# 聊天历史选择与复制 Spec

## 背景

Dragon Code 使用终端界面展示用户消息、模型回复、代码块、工具调用和错误信息。
当前聊天历史可以滚动查看，但 `Ctrl+C` 被高优先级绑定为退出，与 Textual 的文本
复制能力冲突，用户难以保存模型给出的代码和命令。

## 目标

- 用户可以使用鼠标直接拖选聊天历史中的文字。
- 有选中文字时，`Ctrl+C` 复制文字；没有选中文字时，`Ctrl+C` 安全退出。
- Windows Terminal、PowerShell 和 WSL + tmux 中保持一致的核心操作。

## 功能需求

- F1：聊天历史区允许选择全部已完成内容，包括用户消息、模型回复、代码块、工具调用
  和错误信息。
- F2：存在非空选择时，按 `Ctrl+C` 把选择内容复制到系统剪贴板。
- F3：复制成功后不显示提示、不追加历史、不改变选择内容。
- F4：不存在选择内容时，按 `Ctrl+C` 沿用现有安全退出流程。
- F5：选择与复制不影响滚动、输入、流式回复和工具行展示。

## 非功能需求

- N1：优先复用 Textual 原生选择和剪贴板能力，代码保持简单，并为条件分流添加中文注释。
- N2：复制操作不能把 API 密钥或未被用户选择的隐藏数据放入剪贴板。
- N3：复制和退出均为即时操作，不阻塞界面。
- N4：在 Windows Terminal、PowerShell、WSL + tmux 中完成验证。

## 不做的事

- 不新增“复制上一条回复”或“复制代码块”按钮。
- 不实现纯键盘扩展选择。
- 不重写 `RichLog` 或拆分为逐条消息组件。
- 不增加复制成功通知。
- 不保存聊天记录，不实现跨会话历史。
- 不修改终端模拟器或用户的全局 tmux 配置。

## 验收标准

- AC1（F1）：鼠标可以选择聊天历史中的用户、助手、代码和工具文本。
- AC2（F2/F3）：选中文字后按 `Ctrl+C`，剪贴板内容与选择内容一致，界面没有新增提示。
- AC3（F4）：未选择文字时按 `Ctrl+C`，Dragon Code 安全退出。
- AC4（F5）：完成复制后仍可滚动、输入并继续下一轮对话。
- AC5（N1）：实现只使用一个清晰的复制/退出分流动作，并带中文注释。
- AC6（N4）：Windows 自动化测试通过，并在 WSL + tmux 中运行端到端场景。
