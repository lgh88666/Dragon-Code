# ch10：Slash Command 内置命令框架 Spec

## 状态

- 阶段：已批准
- 日期：2026-08-13
- 教材参考：`Vibe Coding提示词复制` ch10 Python 部分

## 背景

Dragon Code 已经拥有 `/help`、`/plan`、`/do`、`/compact`、`/resume`、`/exit` 等命令，但它们通过输入入口中的多段条件判断直接绑定在 TUI 上。

这种方式存在几个问题：

- 新增命令需要继续修改 TUI。
- 命令元数据、帮助文本和执行逻辑相互分散。
- 无法统一处理别名、补全和未知命令。
- 命令难以脱离终端界面单独测试。
- 后续 Skill 系统缺少可复用的命令注册入口。

## 目标

- **G1 集中注册**：通过统一注册中心管理命令名称、别名、描述、用法、类型和执行入口。
- **G2 统一分发**：以 `/` 开头的输入优先交给命令系统，不进入普通 Agent 对话分支。
- **G3 三类执行**：区分纯本地、改变 UI 状态、生成提示词交给 Agent 的命令。
- **G4 界面解耦**：命令通过统一 UI 控制能力影响界面，不依赖具体终端渲染框架。
- **G5 实时补全**：输入 `/` 后实时显示候选菜单，覆盖上、下、Tab、Enter、Esc 全套键位。
- **G6 内置能力**：实现教材建议的 12 条主命令，常用本地操作不消耗 Token。
- **G7 后续扩展**：为 ch11 Skill 接入命令注册中心留下稳定入口，但本章不加载用户自定义命令。

## 功能需求

### 命令注册与分发

- **F1：统一命令定义与注册**

  每条内置命令统一提供名称、别名、描述、用法、执行类型、是否隐藏和执行入口。注册时检测命令名与别名的双向冲突；发生冲突时在启动期明确报错并终止启动。

- **F2：命令解析与分流**

  仅将去除首尾空白后以 `/` 开头的输入视为命令；命令名大小写不敏感。本章所有内置命令均为零参数，命令名后出现额外内容时显示用法错误，不发送给模型。命令优先于普通消息分发，未知命令不得发送给模型。空输入与纯空白输入不参与分发。

- **F3：三类执行模式**

  - `local`：仅执行本地查询或显示逻辑，不调用模型。
  - `local-ui`：本地执行，同时改变会话、模式或界面状态。
  - `prompt`：生成预设任务提示，并作为本轮用户任务交给 Agent。

- **F4：命令与界面解耦**

  命令通过统一控制能力完成系统消息显示、用户任务发送、模式切换、状态读取、界面刷新、会话切换和确认交互，不直接依赖具体终端组件。该控制边界只暴露命令实际需要的能力。

### 自动补全与帮助

- **F5：实时命令补全**

  输入 `/` 或命令前缀时实时显示非隐藏候选菜单：

  - 仅主命令名参与前缀匹配，候选按主命令名称排序；别名仍可执行，但不进入补全菜单。
  - 候选行显示命令名称和一句描述。
  - `↑`、`↓` 切换高亮项。
  - `Tab` 或 `Enter` 将高亮命令填入输入框但不执行。
  - `Esc` 关闭菜单并保留当前输入。
  - 继续输入时实时过滤，出现空格或进入多行输入后关闭菜单。
  - 零匹配时显示“无匹配”；此时 `Tab`、`Esc` 只关闭菜单，`Enter` 提交后进入未知命令提示。
  - 菜单最多显示 8 行，更多候选可通过键盘滚动。
  - 本章不响应鼠标点击候选项。

- **F6：帮助与错误引导**

  `/help` 根据注册中心实时生成非隐藏命令列表；用户在帮助界面选中命令后可查看名称、别名、类型、用法和完整说明。未知命令统一提示用户输入 `/help`，不进入 Agent Loop。

### 上下文、会话与模式

- **F7：上下文与会话操作**

  - `/compact`：沿用 ch08，手动压缩当前对话上下文。
  - `/clear`：保存并关闭当前会话，创建空白新会话；清空消息、Token、Agent 回合与上下文状态，当前模型、权限模式、MCP 连接和长期记忆保持不变。
  - `/session`：打开可搜索的历史会话列表；选中会话后通过交互菜单选择恢复或删除。
  - 删除前明确显示标题和 ID，用户确认后永久删除指定会话。
  - 当前会话禁止删除；单次删除失败不影响其他会话。
  - `/resume`：保留为打开会话恢复列表的兼容入口。

- **F8：计划与执行模式**

  - `/plan`：进入只读 Plan Mode。
  - 进入后由用户在下一条普通消息中输入要规划的任务。
  - `/do`：存在已完成计划时恢复完整工具，并通过用户消息链路执行计划；没有计划时只给出提示。
  - 模式切换后立即刷新状态栏和工具可用范围。

### 记忆、权限与状态

- **F9：记忆管理**

  - `/memory`：打开记忆管理界面，显示用户级与项目级记忆数量、标题和文件名。
  - 用户选中记忆后查看类型、标题与正文，并可继续选择删除。
  - 删除前明确显示目标，确认后删除指定记忆并重建索引。
  - 不提供一键清空全部记忆。
  - 记忆管理在本地执行，不请求主模型。

- **F10：权限管理**

  - `/permission`：打开权限模式选择界面，显示当前模式和各模式含义。
  - 用户在界面中选择 `default`、`acceptEdits` 或 `bypassPermissions`，确认后切换当前运行模式。
  - 切换只影响本次运行，不修改用户级、项目级或本地权限配置。
  - Plan Mode 仍统一由 `/plan`、`/do` 控制。
  - 任何模式都不能绕过危险命令黑名单和路径沙箱。

- **F11：综合状态**

  `/status` 在本地显示：

  - Dragon Code 版本与工作目录。
  - 当前 Provider 与模型。
  - 权限模式与 Plan Mode 状态。
  - 当前会话 ID。
  - 输入、输出、缓存 Token 统计。
  - 当前上下文估算量。
  - 内置工具与 MCP 工具数量。
  - 用户级与项目级记忆数量。

  该命令不请求模型、不消耗 Token。

### Prompt 命令、别名与生命周期

- **F12：代码审查**

  `/review` 打开审查目标选择界面，默认选项是当前 Git 未提交改动；用户也可在界面中输入文件或目录。确认目标后，命令生成固定审查提示并交给 Agent，检查功能错误、安全问题、异步和资源清理、回归风险及测试缺口。审查只开放只读工具，按严重程度输出报告，不修改代码，结束后恢复原有模式。

- **F13：固定别名**

  ```text
  /help        /h  /?
  /compact     /cp
  /clear       /cl
  /plan        /p
  /do          /d
  /session     /ss
  /memory      /mem
  /permission  /perm
  /status      /s
  /review      /r
  /exit        /q  /quit
  ```

- **F14：忙碌状态保护**

  Slash Command 仅在空闲状态执行。Agent Loop、上下文压缩、会话恢复或权限确认期间提交命令，只显示等待提示，不执行、不排队。用户可以先用 Esc 或 Ctrl+C 取消当前任务，再重新输入命令。

- **F15：状态栏提示**

  空闲时状态栏显示 `Tab 补全 · /help`，并保留现有 Provider、模型、权限和 Token 信息；运行任务时由迭代进度与计时暂时替代，任务结束后恢复。

- **F16：退出兼容**

  `/exit`、`/q`、`/quit` 安全退出 Dragon Code，沿用现有资源取消、关闭和终端恢复行为。

## 非功能需求

- **N1：本地响应及时**：纯本地命令不调用 LLM，提交后立即显示结果，不出现可感知等待。
- **N2：界面保持响应**：压缩、恢复、删除和会话扫描期间 TUI 不冻结；耗时操作显示明确状态。
- **N3：状态变更原子**：`/clear`、会话恢复、会话删除和模式切换要么完整成功，要么保留原状态，不能留下半切换的 Conversation、Writer、Token 或 Agent 状态。
- **N4：命令历史合法**：`local` 和 `local-ui` 命令不写入用户对话历史；`prompt` 命令按真实用户消息相同的链路进入 Conversation 和 JSONL，保证角色顺序及工具调用配对合法。
- **N5：单一信息来源**：`/help`、未知命令提示和补全菜单都从注册中心读取命令信息，不维护重复的硬编码命令清单。
- **N6：错误可恢复**：未知命令、多余参数、交互目标不存在、删除失败、记忆不存在、权限切换失败及命令执行异常，都显示可读错误；程序不退出，用户可继续输入。
- **N7：补全菜单有界**：菜单紧邻输入框，最多显示 8 个候选，更多候选可滚动；窄终端下名称和描述不得破坏整体布局。
- **N8：键盘行为稳定**：补全菜单打开和关闭时各键位职责明确；菜单不得吞掉 Alt+Enter 多行输入、Ctrl+C 取消和普通输入框编辑行为。
- **N9：安全删除**：删除会话或记忆必须明确展示目标并等待确认；禁止删除当前会话；不得通过非法 ID 或路径跳出对应数据目录。
- **N10：权限硬防线不退化**：`/permission` 不能关闭危险命令黑名单和路径沙箱；`/review` 必须限制为只读工具，不能只依赖提示词要求模型不修改。
- **N11：现有行为不退化**：ch02–ch09 的流式输出、Agent Loop、Plan Mode、权限、MCP、上下文压缩、会话持久化和自动记忆保持可用。现有 `/exit`、`/plan`、`/do`、`/compact`、`/resume` 的用户可见语义保持一致。
- **N12：资源清理完整**：`/exit` 必须取消当前主任务及后台任务，再关闭会话 Writer、记忆任务和 MCP 连接，最后恢复终端状态。
- **N13：密钥与本地数据安全**：状态、帮助、错误和审查输出不得泄露 API Key、Authorization、密码或本地配置正文；自动会话和记忆数据继续保持 Git 忽略。
- **N14：代码可读、可测试**：使用简单 Python、直接命名和必要中文注释；解析器、注册中心、各类命令及 UI 适配可以在不启动真实 LLM 的情况下测试。
- **N15：教材差异可追溯**：Spec、Plan、Task 和 Checklist 每个阶段都先对照教材 ch10 Python 提示词，并记录教材方案、Dragon Code 方案、差异和保留理由。
- **N16：轻量实现**：命令执行入口只负责零参数校验和调用已有模块；不新增事务框架、事件总线、通用存储层或第二套权限系统。优先复用 SessionManager、MemoryManager、ContextManager、Agent 和 ToolRegistry。

## 不做的事

- 不支持用户自定义命令、Markdown 命令、命令热加载或运行时增删命令，留给 ch11 Skill。
- 不支持用户通过配置修改内置命令名称和别名。
- 不实现命令参数解析器：本章所有内置命令均为零参数，选择目标和后续动作统一通过交互界面完成。
- 不支持多条命令串联执行。
- 不支持命令级权限配置；命令本身的安全边界固定在程序中。
- 不支持补全别名、文件路径、会话 ID 或记忆文件名，只补全命令主名。
- 不支持鼠标点击补全候选，本章只实现键盘操作。
- 不支持模糊搜索、拼写纠正或按使用频率排序，候选只做前缀匹配并按名称排序。
- 不支持批量删除会话、删除当前会话、删除全部记忆或撤销删除。
- 不支持跨项目浏览和恢复会话，只管理当前项目的会话目录。
- `/review` 不自动修改代码、不自动提交 Git，也不提供可配置审查模板。
- 不重新设计状态栏，只增加空闲提示并复用现有显示。
- 不新增事务框架、事件总线、通用存储层或第二套权限系统。
- 不改变 ch02–ch09 已有功能的业务边界。

## 验收标准

- **AC1（F1）注册完整**：启动后注册中心包含 12 条主命令及已确认别名，每条都有名称、描述、用法、类型和执行入口。（验证：注册中心单测 + `/help` 实际输出。）
- **AC2（F1）冲突失败**：构造重复主名、主名与别名冲突、两个别名冲突三种情况，均在注册阶段终止并显示具体冲突名称。（验证：三组单测。）
- **AC3（F2）解析分流**：`/Help`、`/help` 行为一致；普通文本进入 Agent；空白输入无行为；未知 `/xxx` 或 `/help extra` 只显示帮助/用法错误，不请求模型。（验证：解析单测 + 假 LLM 调用次数。）
- **AC4（F3/F4）三类命令解耦**：纯本地命令不修改历史，UI 命令能通过抽象控制界面，Prompt 命令通过普通用户消息链路触发 Agent；命令测试不需要启动真实 TUI。（验证：假 UI 和假 Agent 集成测试。）
- **AC5（F5）实时补全**：依次输入 `/`、`/s`，候选实时从全部命令缩小到匹配命令；候选展示名称和描述，隐藏命令不显示。（验证：Textual 测试 + tmux 观察。）
- **AC6（F5）补全键位**：菜单中 `↑`、`↓` 可以循环选择；`Tab` 或 `Enter` 将选中命令填入输入框但不执行；`Esc` 关闭菜单并保留文本。（验证：Textual 按键测试 + tmux 实操。）
- **AC7（F5）补全边界**：多行输入不显示菜单；零匹配显示“无匹配”；最多展示 8 行并支持键盘滚动；不响应鼠标选择。（验证：组件测试 + 窄窗口观察。）
- **AC8（F6）帮助单一信源**：`/help` 按名称排序显示全部非隐藏命令、别名和描述；在帮助界面选中 `/review` 后显示其详情；新增测试命令后帮助与补全自动出现，无需修改帮助文本。（验证：注册中心驱动测试 + Textual 交互测试。）
- **AC9（F7）手动压缩**：`/compact` 沿用现有事件流完成上下文压缩并显示压缩前后结果。（验证：原有测试 + tmux 执行。）
- **AC10（F7）清空并新建会话**：执行 `/clear` 后消息、Token、回合与上下文状态归零，新消息写入新的 JSONL；旧会话仍能在 `/session` 和 `/resume` 中恢复；模型、权限、MCP 和长期记忆不变。（验证：集成测试 + 磁盘文件检查。）
- **AC11（F7）会话管理**：`/session` 和 `/resume` 打开可搜索列表；选中目标后可恢复指定会话；目标失效时显示错误且当前会话不变。（验证：会话集成测试 + Textual 交互测试 + tmux。）
- **AC12（F7/N9）安全删除会话**：在 `/session` 界面选中会话并选择删除后显示标题与 ID；取消后文件仍在，确认后目标目录消失；当前会话和越界目标均被拒绝。（验证：临时目录测试 + tmux 确认框。）
- **AC13（F8）计划模式**：`/plan` 只开放只读工具并刷新模式显示，随后一条普通消息作为规划任务；已有计划时 `/do` 恢复全工具并通过用户消息链路执行；无计划时只提示、不请求模型。（验证：既有 Plan Mode 测试 + tmux。）
- **AC14（F9/N9）记忆管理**：`/memory` 界面区分用户级和项目级；选中目标后可查看详情或删除；取消删除时不改变文件，确认后只删除目标并重建索引；越界目标被拒绝。（验证：临时记忆目录测试 + Textual 交互测试 + tmux。）
- **AC15（F10）权限管理**：`/permission` 打开模式列表；在界面中选择模式后立即更新 Agent 和状态栏，但不修改 YAML；重启后恢复配置默认值；Bypass 模式仍被黑名单和沙箱拦截。（验证：单测 + Textual 交互测试 + 配置文件前后对比。）
- **AC16（F11）综合状态**：`/status` 显示已确认的版本、目录、Provider、模型、模式、会话、Token、上下文、工具和记忆信息；执行前后 LLM 调用次数和 Token 不增加。（验证：假 LLM + tmux 输出。）
- **AC17（F12/N10）只读审查**：`/review` 打开目标选择界面，可选择未提交改动或输入指定路径；确认后请求作为用户消息写入历史和 JSONL；审查期间只有只读工具可用，文件和 Git 状态不发生修改，结束后原模式不变。（验证：假模型工具调用测试 + Textual 交互测试 + 真实 tmux 审查。）
- **AC18（F13）别名一致**：每个已确认别名与主命令行为一致，主命令和别名均大小写不敏感；补全只展示并匹配主命令名。（验证：参数化单测。）
- **AC19（F14）忙碌保护**：Agent Loop、压缩、恢复和权限确认期间提交任一命令，均只显示等待提示，不执行、不排队；取消回到空闲后可重新执行。（验证：可控慢任务测试 + tmux。）
- **AC20（F15）状态栏提示**：空闲时显示 `Tab 补全 · /help`；任务运行时正常显示迭代和计时；任务结束后提示恢复，原有 Provider、模型、权限和 Token 信息仍正确。（验证：Textual 测试 + tmux 截图。）
- **AC21（F16/N12）安全退出**：`/exit`、`/q`、`/quit` 行为一致；退出后无 Dragon Code、记忆或 MCP 后台进程，终端状态正常，当前会话文件完整。（验证：tmux 退出 + 进程检查。）
- **AC22（N11–N16）全量非回归**：格式、lint、全量测试通过；真实会话、自动记忆和密钥不进入 Git；ch02–ch09 的核心场景继续通过。（验证：项目标准命令 + Git 忽略和敏感信息扫描。）

## 教材 Python 提示词对照

### 共同设计

- 12 条主命令、集中注册中心、三类命令、UI 抽象、启动期冲突检测。
- 所有内置命令均为零参数，后续选择通过交互界面完成。
- `/help` 与补全菜单由注册中心驱动。
- 实时补全覆盖方向键、Tab、Enter、Esc，隐藏命令不参与展示。
- Prompt 命令走普通用户消息的历史与持久化路径。
- 本章不做用户自定义命令和命令级权限系统。

### Dragon Code 保留差异

| 设计点 | 教材 Python 提示词 | Dragon Code | 保留理由 |
|---|---|---|---|
| Enter/Tab | 直接执行候选 | 只填入输入框 | 避免误执行删除、清空和权限切换命令 |
| 忙碌状态 | 纯本地命令可执行 | 所有命令只在空闲态执行 | 简化并发状态，避免输入分流竞争 |
| `/session` | 只显示当前会话 | 交互列表、恢复、确认删除 | 解决真实会话管理需求，不要求记忆 ID |
| `/memory` | 只列文件名 | 交互列表、查看、确认删除 | 允许用户管理 ch09 长期记忆 |
| `/permission` | 只显示模式 | 交互查看并临时切换模式 | 与现有 Shift+Tab 能力一致 |
| `/review` | 直接使用固定目标 | 交互选择当前改动或指定目标，只读执行 | 提升实用性并保持安全 |
| 状态栏 | 保持原样 | 空闲时增加命令提示 | 提高命令可发现性 |

这些差异均已由用户逐项确认。后续 Plan、Task 和 Checklist 继续对照教材 Python 提示词，并记录新的差异。
