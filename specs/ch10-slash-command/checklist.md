- [x] **场景 1：补全和帮助**——启动 Dragon Code，输入 `/`，用上下键选择，Enter 只填入，再次 Enter 打开帮助；选择 `/review` 能看到详情。【AC5–AC8】

- [ ] **场景 3：清空与恢复**——先进行一轮真实对话，执行 `/clear` 后界面和 Token 归零，再用 `/resume` 搜索并恢复旧会话，模型能引用恢复内容。【AC10/AC11】
- [ ] **场景 4：会话删除**——在 `/session` 中选择非当前测试会话，先取消删除确认其仍在，再确认删除并观察列表刷新；当前会话不可删除。【AC12】
- [ ] **场景 5：记忆管理**——通过 `/memory` 查看一条测试记忆，取消一次删除，再确认删除并检查索引更新。【AC14】
- [x] **场景 6：权限切换**——通过 `/permission` 切换运行时模式，状态栏立即更新；重启后恢复配置默认值。【AC15】
- [x] **场景 7：只读审查**——执行 `/review` 选择当前 Git 改动，让真实模型完成审查；观察只读工具调用和最终报告，工作树内容不被修改。【AC17】
