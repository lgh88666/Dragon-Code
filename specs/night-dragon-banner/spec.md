# Dragon Code 夜行小龙 Banner Spec

## 背景

当前 Dragon Code 使用 ASCII 猫咪作为启动图案，与项目的“龙”主题不一致。本次将其替换为
原创夜行小龙头像，在不挤占对话空间的前提下增强品牌辨识度。

## 目标

- 采用约 5 行高、24 列宽的紧凑 ASCII 龙头。
- 气质可爱、敏捷、略带锐利感。
- 不直接复刻《驯龙高手》夜煞的具体造型。
- 保持现有应用名、版本、工作目录和就绪提示不变。

## 功能需求

- F1：启动界面原有 ASCII 猫咪替换为原创夜行小龙头像。
- F2：图案采用正面龙头构图，包含短角、眼睛和龙脸轮廓，整体约 5 行高、24 列宽。
- F3：只使用等宽 ASCII 字符，避免不同终端对 Unicode 字符宽度解释不一致。
- F4：图案继续通过现有 Banner 渲染流程展示，不改变应用名、版本号、工作目录和就绪提示。
- F5：除启动图案外，不改变对话、Provider、输入、流式输出或界面布局等功能。

## 非功能需求

- N1：图案宽度不超过 24 列、高度不超过 5 行，不能明显压缩对话区域。
- N2：在 Windows Terminal、PowerShell、WSL 和 tmux 等常见终端中保持对齐。
- N3：图案内容集中定义，代码保留简短中文说明，便于后续替换和维护。
- N4：设计仅借鉴“黑色夜行龙、可爱且敏捷”的抽象气质，不复制夜煞的标志性外形或官方素材。
- N5：现有自动测试和代码质量检查继续通过。

## 不做的事

- 不制作 PNG、SVG、图标或 README Logo。
- 不加入动画、闪烁、随机表情或交互效果。
- 不修改 Banner 的文字、颜色、版本信息和工作目录展示。
- 不调整 TUI 布局、间距、状态栏或对话区。
- 不引入新的依赖。
- 不直接复制《驯龙高手》夜煞的图像或 ASCII Art。

## 验收标准

- AC1：启动 Dragon Code 后，原猫咪图案不再出现，顶部展示原创夜行小龙头像。
- AC2：龙头像不超过 5 行，每行不超过 24 个 ASCII 字符。
- AC3：图案能明显辨认出短角、双眼和龙脸轮廓，整体呈现可爱但略带锐利感。
- AC4：Banner 中的 Dragon Code 名称、版本号、工作目录和就绪提示与修改前一致。
- AC5：在标准宽度和窄终端中启动，图案均保持对齐，不与其他内容重叠。
- AC6：Banner 单元测试、完整 pytest、Ruff 格式和静态检查全部通过。
