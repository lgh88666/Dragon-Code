# Dragon Code 三头龙徽章 Banner Spec

## 背景

当前 Dragon Code 使用原创正面小龙头像，但图案辨识度不足。本次参考坦格利安家族的经典
三头龙家徽，将启动图案改为紧凑的红色环形三头龙 ASCII 徽章，强化项目的龙族视觉。

## 目标

- 启动界面展示紧凑的环形三头龙 ASCII 徽章。
- 图案使用红色，体现坦格利安家徽的经典视觉。
- 高度控制在约 5 行、宽度不超过 24 列。
- 保留现有应用名称、版本、工作目录、就绪提示和界面布局。
- 只修改启动 Banner，不影响其他功能。

## 功能需求

- F1：启动界面原有的正面小龙头像替换为环形三头龙 ASCII 徽章。
- F2：徽章包含三个可辨认的龙头，并以左右展开、下方收拢的轮廓体现环形家徽特征。
- F3：启动 Banner 整体以红色显示，文字仍保持清楚可读。
- F4：图案只使用等宽 ASCII 字符，避免不同终端对 Unicode 字符宽度解释不一致。
- F5：图案继续通过现有 Banner 渲染流程展示，应用名称、版本号、工作目录和就绪提示保持不变。
- F6：除启动图案及其颜色外，不改变对话、Provider、输入、流式输出和界面布局。

## 非功能需求

- N1：图案高度为 5 行、宽度不超过 24 列，不明显压缩对话区域。
- N2：在 Windows Terminal、PowerShell、WSL 和 tmux 等常见终端中保持对齐。
- N3：图案内容集中定义，代码保留简短中文说明，便于后续替换和维护。
- N4：图案是对三头龙家徽的 ASCII 化改编，不嵌入或分发影视官方图片素材。
- N5：不引入新依赖，现有自动测试和代码质量检查继续通过。

## 不做的事

- 不制作 PNG、SVG、应用图标或 README Logo。
- 不加入动画、闪烁、随机效果或交互效果。
- 不修改应用名称、版本信息、工作目录和就绪提示的文字。
- 不调整 TUI 布局、间距、状态栏或对话区。
- 不改变对话和 Provider 等业务逻辑。
- 不引入新的依赖。

## 验收标准

- AC1：启动 Dragon Code 后，旧正面龙头不再出现，顶部展示新的三头龙徽章。
- AC2：徽章恰好为 5 行，每行不超过 24 个 ASCII 字符。
- AC3：图案可辨认出向左、向上和向右的三个龙头，整体轮廓向下收拢。
- AC4：启动 Banner 以红色显示，文字清楚可读。
- AC5：Dragon Code 名称、版本号、工作目录和就绪提示与修改前一致。
- AC6：在标准宽度和窄终端中启动，图案保持对齐，不与其他内容重叠。
- AC7：Banner 单元测试、完整 pytest、Ruff 格式和静态检查全部通过。
