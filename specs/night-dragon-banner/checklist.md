# Dragon Code 夜行小龙 Banner Checklist

> 每一项通过自动测试或实际启动界面观察验证，并记录实际证据。

## 实现完整性

- [ ] **猫咪已替换（AC1/F1）**  
  验证：启动 Dragon Code，顶部不再出现 `/\_/\`、`o.o` 等猫咪特征，改为夜行小龙头像。

- [ ] **图案尺寸合规（AC2/F2/N1）**  
  验证：单元测试确认图案恰好为 5 行，且每行不超过 24 个字符。

- [ ] **图案特征清晰（AC3/F2）**  
  验证：目视确认图案能辨认出一对短角、两只眼睛、脸部尖角和下颌轮廓，整体可爱且略带锐利感。

- [ ] **仅使用 ASCII（F3/N2）**  
  验证：单元测试遍历图案全部字符，确认字符编码均小于 128。

- [ ] **原有 Banner 文字不变（AC4/F4）**  
  验证：调用 `render_banner("0.1.0", "/tmp/demo")`，输出仍包含 Dragon Code、版本、
  `/tmp/demo` 和就绪提示。

- [ ] **修改范围正确（F5）**  
  验证：Git 差异中运行代码只修改 `prompt.py`，不修改 TUI、TCSS、Provider、会话或依赖。

- [ ] **资源集中且有说明（N3）**  
  验证：图案只在 `DRAGON_BANNER` 中定义，旁边有简短中文注释。

- [ ] **原创性边界（N4）**  
  验证：图案不含具体影视角色名称、官方素材或尾翼等标志性结构。

- [ ] **标准与窄终端兼容（AC5/N2）**  
  验证：在标准宽度和约 42 列宽度下显示，图案均保持对齐且不与其他内容重叠。

## 自动测试与质量

- [ ] **完整质量门禁（AC6/N5）**  
  验证：以下专项测试、完整测试、格式检查、静态检查和差异检查全部通过。

- [ ] `uv run pytest tests/test_prompt.py -q` 返回退出码 0。
- [ ] `uv run pytest -q` 返回退出码 0。
- [ ] `uv run ruff format --check .` 返回退出码 0。
- [ ] `uv run ruff check .` 返回退出码 0。
- [ ] `git diff --check` 返回退出码 0。

## 端到端场景

### 场景 1：标准终端

- [ ] 在项目目录运行 `uv run dragon-code`。
- [ ] 顶部显示完整的 5 行夜行小龙头像。
- [ ] 应用名、版本、工作目录、就绪提示和其他界面元素保持正常。

### 场景 2：窄终端

- [ ] 将终端宽度调整到约 42 列并启动或刷新界面。
- [ ] 龙头像保持对齐，不截断、不重叠输入框或对话区。

### 场景 3：tmux 验收

- [ ] 在 WSL/Linux 的 tmux 会话中启动 Dragon Code。
- [ ] 使用 `tmux capture-pane -p -S -` 或截图保存顶部 Banner 证据。
- [ ] 图案在 tmux 中的行宽、反斜杠和左右轮廓均正确显示。
- [ ] 输入一条真实对话请求，确认只改变了 Banner，聊天功能仍正常。
