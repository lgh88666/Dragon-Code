# Dragon Code 夜行小龙 Banner Checklist

> 每一项通过自动测试或实际启动界面观察验证，并记录实际证据。

## 实现完整性

- [x] **猫咪已替换（AC1/F1）**
  验证：启动 Dragon Code，顶部不再出现 `/\_/\`、`o.o` 等猫咪特征，改为夜行小龙头像。
  证据：专项测试确认旧猫咪特征不存在，`render_banner()` 实际输出为龙头像。

- [x] **图案尺寸合规（AC2/F2/N1）**
  验证：单元测试确认图案恰好为 5 行，且每行不超过 24 个字符。
  证据：实测 `LINES 5`、`MAX_WIDTH 21`。

- [x] **图案特征清晰（AC3/F2）**
  验证：目视确认图案能辨认出一对短角、两只眼睛、脸部尖角和下颌轮廓，整体可爱且略带锐利感。
  证据：终端输出中可见双角、两个 `o` 眼睛、`< >` 脸部尖角和 `===` 下颌表情。

- [x] **仅使用 ASCII（F3/N2）**
  验证：单元测试遍历图案全部字符，确认字符编码均小于 128。
  证据：实测 `ASCII True`。

- [x] **原有 Banner 文字不变（AC4/F4）**
  验证：调用 `render_banner("0.1.0", "/tmp/demo")`，输出仍包含 Dragon Code、版本、
  `/tmp/demo` 和就绪提示。
  证据：专项测试和实际打印均确认四项文字存在。

- [x] **修改范围正确（F5）**
  验证：Git 差异中运行代码只修改 `prompt.py`，不修改 TUI、TCSS、Provider、会话或依赖。
  证据：`git diff --name-only` 的运行文件只有 `src/dragon_code/prompt.py`。

- [x] **资源集中且有说明（N3）**
  验证：图案只在 `DRAGON_BANNER` 中定义，旁边有简短中文注释。
  证据：源码检查通过。

- [x] **原创性边界（N4）**
  验证：图案不含具体影视角色名称、官方素材或尾翼等标志性结构。
  证据：源码仅包含原创正面龙头和原创性说明。

- [x] **标准与窄终端兼容（AC5/N2）**
  验证：在标准宽度和约 42 列宽度下显示，图案均保持对齐且不与其他内容重叠。
  证据：Textual Pilot 的标准布局和 42×18 窄终端测试通过。
